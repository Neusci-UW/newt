Help

How Newt keeps your work, the keys that work on every tab, and what the words on Analysis mean.

Keys

Esc
Stops any stimulus, from any tab, and sets the outputs to 0 V.
S
Save the session in its Newt file (the first time, it asks where). Add Shift to save it as another file.
O
Open a Newt file.
C
On Record, while a trial is recording: type a comment. It's saved at that moment in the trial.

Your files

A Newt file (.newt) holds a whole session: its trials, what you worked out on Analysis, the DataPad and the plots, and the stimulus settings. Open it again and Newt is as you left it. The Qt version of Newt opens the same files.

Newt records each trial to the computer as it comes in, into a folder of its own, so nothing is lost if the computer crashes. Save packs that folder into one file you can keep, share or hand in.

Import opens a LabChart or MATLAB .mat (it isn't changed: Newt keeps its own copy), or an .argus file (Newt's old name). Export writes the trials as a .mat for LabChart or MATLAB.

The stimulator is safe to leave

Every stimulus ends at 0 V. The outputs also go to 0 V when you press Esc or Stop, when you close Newt's window, and a few seconds after the last Newt page closes (a browser tab, say), so nothing is left on.
