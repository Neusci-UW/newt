Shown value = volts at the input × scale + offset. An amplifier with a gain of 100, shown in mV: scale = 1000 mV per V ÷ 100 = 10. Only the volts are saved; scale and offset go with each trial, so they can be fixed later.

Calculated channels

Worked out from the channels while you watch, like LabChart's channel calculations: a filter, the difference of two channels, a rate meter… Never recorded: Analysis works them out from the trials.
