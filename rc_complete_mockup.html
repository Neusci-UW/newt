Dashed = new. The switched "current source" is a mixed cation channel: one switch connects a Na⁺ part and a K⁺ part together. Each part uses the same ENa / EK battery as its leak, so the mixed channel pulls V toward a value between them (about −13 mV with equal parts). Leak Na⁺, K⁺ and Cl⁻ are always on: rest ≈ −77 mV; switch closed → V∞ ≈ −43 mV. Current chart: Imix (Na⁺ + K⁺ parts), INa, IK, ICl, IC, dashed sum.
